## 🛠️ ขั้นตอนที่ดำเนินการไปแล้ว

### 1. อัปเดตไฟล์แผนที่ (Frontend Map Layout)
- **ไฟล์:** `MapLayoutData/Mapdata.MD`
- **สิ่งที่ทำ:** ทุกแถวที่เป็น `S09-Lx-x | Toys` → เปลี่ยนเป็น `S09-Lx-x | Stationery`
- **สิ่งที่เพิ่ม:** สร้างแถว `T09-Lx-x | Toys` ใหม่ (Clone โครงสร้างชั้นวางจาก S09)

### 2. อัปเดต Validation Rules (ระบบตรวจสอบตำแหน่ง)
- **ไฟล์:** `src/utils/rackUtils.js`
- **สิ่งที่ทำ:**
  - `STATIONERY` zone: เพิ่ม `S09` เข้าไปในรายการ (5 ชั้น, 4 เซคชั่น)
  - `TOYS` zone: เปลี่ยนจาก `S09` เป็น `T09` (5 ชั้น, 4 เซคชั่น)

### 3. ย้ายข้อมูลสินค้าใน Database (Data Migration)
- **Table:** `location_inventory` ใน Supabase
- **SQL ที่ใช้:**
```sql
UPDATE location_inventory
SET rack_location = REPLACE(rack_location, 'S09', 'T09')
WHERE branch_id = 'ສີວິໄລ'
  AND rack_location LIKE 'S09%';
```
- **ผลลัพธ์:** สินค้าทั้งหมดที่เคยอยู่ `S09-Lx-x` ถูกย้ายไป `T09-Lx-x` เรียบร้อยแล้ว
