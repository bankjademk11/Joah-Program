# โปรแกรมค้นหาสินค้าด้วยรูปภาพ AI

โปรแกรมนี้ใช้กล้องมือถือหรือเว็บแคมถ่ายรูปสินค้า แล้วค้นหาสินค้าที่มีลักษณะใกล้เคียงที่สุดจากฐานข้อมูลรูปสินค้า พร้อมแสดง Barcode ของผลลัพธ์

## สิ่งที่ผู้ดูแลต้องเตรียม

โฟลเดอร์ที่แจกต้องมีไฟล์และโฟลเดอร์สำคัญดังนี้

```text
โปรแกรมค้นหาสินค้า/
├─ start_app.bat
├─ install_windows.bat
├─ run_app.ps1
├─ app.py และไฟล์ .py อื่น ๆ
├─ requirements.txt
├─ index_data/
│  ├─ product_index.faiss
│  ├─ product_labels.json
│  ├─ product_embeddings.npy
│  └─ meta.json
└─ images/                 (มีไว้สำหรับสร้างหรือเพิ่มสินค้า)
```

สามารถ zip โฟลเดอร์ `files` ทั้งหมดแล้วส่งให้พนักงานได้ แต่ไม่ควรตัดไฟล์ใน `index_data` ออก เพราะเป็นฐานข้อมูลที่ใช้ค้นหาสินค้า

## การติดตั้งครั้งแรกบนเครื่องพนักงาน

1. ติดตั้ง **Python 3.11, 3.12 หรือ 3.13 (64-bit)** จาก [python.org](https://www.python.org/downloads/windows/)
2. ตอนติดตั้ง Python ให้เลือก **Add Python to PATH**
3. แตกไฟล์โปรแกรมไว้ในโฟลเดอร์ที่ผู้ใช้มีสิทธิ์เขียน เช่น Desktop หรือ Documents
4. ดับเบิลคลิก `install_windows.bat`
5. รอให้โปรแกรมติดตั้งส่วนประกอบจนเสร็จ การติดตั้งครั้งแรกต้องใช้อินเทอร์เน็ต
6. หลังติดตั้งเสร็จ ให้ดับเบิลคลิก `start_app.bat`

ครั้งแรกที่เปิดระบบ โมเดล DINOv2 อาจต้องดาวน์โหลดน้ำหนักโมเดลเพิ่มเติม จึงควรมีอินเทอร์เน็ตและอาจใช้เวลาหลายนาที หลังจากดาวน์โหลดแล้ว ครั้งถัดไปจะไม่ต้องดาวน์โหลดซ้ำ

## การใช้งานประจำวัน

ดับเบิลคลิก `start_app.bat` ระบบจะเปิดหน้าต่างโปรแกรมและเปิดเว็บอัตโนมัติที่:

```text
http://127.0.0.1:5000
```

อนุญาตให้เว็บใช้กล้อง จากนั้นกด **ถ่ายรูป & ค้นหา** ระบบจะแสดง Barcode ที่มีความคล้ายสูงสุด 5 รายการ

เมื่อต้องการปิดระบบ ให้ปิดหน้าต่างสีดำที่เปิดขึ้นมาพร้อมโปรแกรม

## การเพิ่มสินค้าใหม่

ผู้ดูแลสามารถวางรูปสินค้าใหม่ไว้ในโฟลเดอร์ใหม่ เช่น `new_images` โดยตั้งชื่อไฟล์เป็น Barcode เช่น:

```text
new_images\8850123456789.jpg
```

จากนั้นรันคำสั่งใน Command Prompt ที่โฟลเดอร์โปรแกรม:

```bat
.runtime\Scripts\python.exe add_images.py --images_dir .\new_images --index_dir .\index_data
```

หลังเพิ่มเสร็จ ให้ปิดและเปิด `start_app.bat` ใหม่ เพื่อให้ระบบโหลด index ล่าสุด

## ข้อควรทราบ

- โปรแกรมนี้ค้นหาจากลักษณะภาพสินค้า ไม่ได้อ่านเส้น Barcode ด้วยเครื่องสแกนโดยตรง
- Barcode ต้องเป็นชื่อไฟล์รูปสินค้า
- ถ่ายรูปให้เห็นสินค้าเต็มชิ้นและมีแสงเพียงพอเพื่อผลลัพธ์ที่ดี
- ถ้าใช้กล้องมือถือจากเครื่องอื่น ต้องเปิดผ่าน `localhost` บนเครื่องนั้น หรือปรับระบบเครือข่ายเพิ่มเติมโดยผู้ดูแล
- หากกล้องไม่ทำงาน ให้ใช้ Chrome หรือ Edge และตรวจสอบสิทธิ์การใช้กล้อง
- ห้ามลบหรือแก้ไขไฟล์ใน `index_data` ด้วยมือ

## การแก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| เปิด `start_app.bat` แล้วแจ้งว่ายังไม่ได้ติดตั้ง | รัน `install_windows.bat` ก่อน |
| ไม่พบ Python | ติดตั้ง Python 3.11–3.13 แบบ 64-bit และเลือก Add Python to PATH |
| ไม่พบฐานข้อมูลสินค้า | ตรวจสอบว่ามี `index_data\product_index.faiss` |
| เว็บเปิดแต่ค้นหาไม่ได้ | ตรวจสอบว่ามีไฟล์ index ครบและลองปิด/เปิดโปรแกรมใหม่ |
| ติดตั้ง PyTorch ไม่ได้ | หลีกเลี่ยง Python 3.14 และใช้ Python 3.11–3.13 |
| กล้องไม่ขึ้น | อนุญาต Camera ให้เบราว์เซอร์และใช้ Chrome/Edge |
